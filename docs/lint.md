# Проверка Android Lint

Команда: `gradlew.bat :app:lintDebug :app:lintRelease --offline`.
Перед запуском установить JAVA_HOME, как описано в AGENTS.md.

В `app/lint.xml` оставлены точечные исключения для принятых ограничений:

- `OldTargetApi`, `GradleDependency`: SDK и версии зависимостей закреплены
  для ГУ Android 9 и локального моста libFLAC/Media3 1.2.1. Проверка Lint
  не должна требовать обновления стека или JNI-библиотеки.
- `DiscouragedApi` в манифесте: экран ГУ всегда ландшафтный; адаптация
  окон Android 16 не относится к целевому устройству.
- `ExportedService` в манифесте: MediaSessionService открыт системным
  контроллерам воспроизведения и кнопкам руля. Обязательное разрешение
  стороннего клиента изменило бы этот контракт.
- `UseCompoundDrawables` для хлебных крошек: отдельная стрелка меняет
  VISIBLE/INVISIBLE, сохраняя отступ последнего уровня. Compound drawable
  без дополнительной логики меняет ширину элемента.
- `InefficientWeight` для списка жанров: исходная высота 360dp нужна
  в обычном окне, а вес позволяет сжать список при появлении клавиатуры.
  Высота 0dp в диалоге wrap_content не задаёт желаемый размер списка.
- `Overdraw` для строки выпадающего списка настроек: фон выпадающего
  окна задаётся отдельно от Activity и должен соответствовать панели
  выбранной палитры. Предположение Lint о фоне окна Activity здесь неточно.

Общие проверки этих категорий для остальных файлов остаются включёнными.
