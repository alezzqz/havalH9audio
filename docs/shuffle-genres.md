# Жанры в случайном воспроизведении

Кнопка с иконкой фильтра находится рядом с кнопкой случайного воспроизведения.
Она подсвечивается только при заданном фильтре и включённом шафле;
счётчик выбранных жанров на кнопке не отображается.
Окно использует общий с настройками и эквалайзером фон с окантовкой;
крупные кнопки действий размещены внутри панели без отдельной тонированной подложки.
Диалог показывает жанры текущего накопителя, число треков каждого жанра,
поиск и переключатель «Все жанры». «Без жанра» объединяет файлы без тегов
и файлы с отсутствующим или пустым жанром.

Выбранные категории объединяются по ИЛИ. Трек с несколькими жанрами
попадает в выбор один раз. «Все жанры» отключает ограничение, включая
категории, появившиеся при последующих сканированиях.

Фильтр действует только на случайный выбор: следующий трек, автопереход
и кнопки руля. Просмотр папок, ручной запуск и последовательный режим
не ограничиваются. Применение не прерывает текущую песню и очищает историю
шафла. В новую историю не попадают вручную запущенные треки вне фильтра.
При пустом результате «Применить» недоступно. Если сохранённый выбор
опустел после обновления библиотеки, появляется сообщение; автоматического
возврата ко всем жанрам нет.

Выбор сохраняется по идентификатору накопителя в `folder_sound`, отдельно
от профилей звука и кэша Room. Перечитывание библиотеки, отключение,
перезапуск, сброс EQ и удаление профилей звука его не сбрасывают.
Полная очистка накопителя удаляет также его фильтр жанров.

MP3: ID3v1, ID3v2.2 TCO и ID3v2.3/2.4 TCON; числовые жанры 0–147
переводятся в названия. FLAC: GENRE в Vorbis Comment, включая повторные
поля. CUE: REM GENRE; при отсутствии используется жанр исходного файла.
Несколько значений разделяются NUL или точкой с запятой. Слеш и запятая
сохраняются в названии (`Pop/Rock`, `Rock, Alternative`). Пробелы и регистр
нормализуются; разные языки и синонимы автоматически не объединяются.

Room v4 добавляет только `root.genreVersion`. Миграция с v3 сохраняет
готовые библиотеки и помечает их как не содержащие прочитанных жанров.
Такой кэш доступен для обычного воспроизведения; диалог предлагает ручное
обновление именно текущего накопителя с предупреждением об остановке.
Остальные накопители не пересканируются. До обновления старые пустые поля
не показываются как достоверная категория «Без жанра».

## Ручная проверка на Haval_H9

Проверены на Android 9 / API 28: миграция существующей библиотеки без скана,
12 тестовых треков с перечисленными форматами тегов, объединение жанров без
дублирования, пустой выбор, поиск и отмена, выбор только Rock и только
«Без жанра», один подходящий трек и автопереход CUE, сохранение после перезапуска и отсутствие
автоматического расширения фильтра после удаления последнего совпадения.
Проверки ниже также служат перечнем сценариев для последующих изменений.

- Все жанры; один жанр; несколько жанров; только «Без жанра»; исключение
  «Без жанра»; пустой выбор; поиск, отмена и повторное открытие диалога.
- MP3 с числовым и текстовым жанром, UTF-16 и несколькими значениями;
  FLAC с несколькими GENRE; CUE с REM GENRE и без него.
- Следующий трек, автопереход, история, ручной запуск трека вне фильтра,
  один подходящий трек и возврат к последовательному режиму.
- Сохранение после перезапуска, перечитывания и смены источника; отсутствие
  совпадений после обновления; отключение накопителя при открытом диалоге.
- Миграция готового кэша v3 без автоматического скана; ручное обновление
  одного источника; сохранность кэша и настроек другого источника.
